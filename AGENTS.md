# SKINFA project instructions

For frontend work, read .agents/skills/skinfa-ui-craft/SKILL.md, .agents/skills/impeccable/SKILL.md, and .agents/skills/design-taste-frontend/SKILL.md and follow them when relevant. Taste Skill guides art direction and anti-generic visual quality; Impeccable guides design critique and refinement; SKINFA UI Craft provides project-specific motion, touch, and implementation guardrails. For browser testing and verification, also read .agents/skills/playwright/SKILL.md. For Figma-based design implementation, also read .agents/skills/figma-mcp/SKILL.md; use Figma design context and existing project components as the source of truth.

Keep existing product behavior, data flows, authentication, checkout, and brand decisions intact unless the task explicitly asks to change them. Inspect the current implementation before editing; make focused changes; verify responsive behavior, accessibility, RTL layout, and interactive states.

Use purposeful, restrained motion. Prioritize smoothness, mobile touch behavior, clear feedback, and performance over decorative animation. Respect reduced-motion preferences.

This project guide is inspired by the public Emil Kowalski skills collection: https://github.com/emilkowalski/skills. It is a local project instruction, not the upstream skills package itself.
